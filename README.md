# 恶搞四川麻将 · 联机版

## 怎么开玩
1. 电脑上需要装 [Node.js](https://nodejs.org)（装 LTS 版本，一路下一步即可）。本项目零依赖，装完 Node 不用 npm install。
2. 双击 `开始游戏.bat`（或命令行运行 `node server.js`）。
3. 自己浏览器打开 http://localhost:3000 → 输昵称 → 选 4 局或 8 局 → 创建房间（你是房主）。
4. 房间页会显示邀请链接，如 `http://192.168.x.x:3000/?r=XXXX`，复制发给朋友，他们打开就能加入。
5. 人不够没关系，点"开始游戏"后空位自动由机器人补齐。
6. **恶搞规则**：前几局完全正常的四川麻将（定缺、血战到底、碰杠胡、自摸翻倍）；最后一局房主必定"天胡·清一色龙七对·32番"，以最高倍数通吃三家 😏。

## 朋友不在同一 WiFi 怎么办
本服务器跑在你电脑上，链接只在内网有效。要给外地朋友玩，任选其一：
- **cloudflared（免费，推荐）**：下载 cloudflared 后运行 `cloudflared tunnel --url http://localhost:3000`，它会给你一个 `https://xxx.trycloudflare.com` 的公网地址，把地址加上 `/?r=房间号` 发给朋友即可。
- **ngrok**：`ngrok http 3000`，用法相同。

## 文件说明
- `server.js`：游戏服务器（WebSocket 手写实现，零依赖），发牌、判定、计分、机器人和"最后一局暗改"都在服务器端，玩家改不了牌。
- `public/index.html`：客户端，麻将牌面用 SVG 绘制（筒=圆圈、条=竹节、万=汉字）。
